# doc-brain

Standalone Relay docs brain for `docs.rizom.ai`.

## What it owns

- `brain.yaml` — Relay docs app config
- `src/site.ts` — app-local docs route composition
- deploy workflow/secrets for the running docs app

Docs content is generated from `rizom-ai/brains` and synced into:

```text
rizom-ai/doc-brain-content
```

## Local start

```bash
bun install
bunx brain start
```

Required local secrets live in `.env` copied from `.env.example`.

## Content

The app pulls markdown docs from `rizom-ai/doc-brain-content` via the
`directory-sync` plugin. Runtime content lives in `brain-data/` and is ignored.

## Deploy

Deploy files are generated by `brain init --deploy` and use the normal standalone
brain deployment path.
