# Doc Brain Remaining Work

`rizom-ai/doc-brain` is the standalone Relay docs brain for `docs.rizom.ai`.

## Ownership

- `rizom-ai/brains` owns source docs, `docs/docs-manifest.yaml`, `scripts/sync-docs-content.ts`, and the `doc` entity package.
- `rizom-ai/doc-brain-content` owns generated docs content under `doc/*.md`.
- `rizom-ai/doc-brain` owns app config, route composition, runtime sync, deploy workflow, and production secrets.

## Current status

- `brain.yaml` uses Relay `preset: default` with `add: [docs]`.
- Relay interfaces remain enabled, including Discord, MCP, webserver, and A2A.
- Runtime content sync reads `rizom-ai/doc-brain-content` with `GIT_SYNC_TOKEN`.
- Deploy files are generated by `brain init --deploy --regen` and currently match the generator.
- Production deploy has not been verified yet.

## Remaining work

### 1. Configure repo secrets

- `AI_API_KEY`
- `GIT_SYNC_TOKEN`
- `MCP_AUTH_TOKEN`
- `DISCORD_BOT_TOKEN`
- `HCLOUD_TOKEN`
- `HCLOUD_SSH_KEY_NAME`
- `HCLOUD_SERVER_TYPE`
- `HCLOUD_LOCATION`
- `KAMAL_SSH_PRIVATE_KEY`
- `KAMAL_REGISTRY_PASSWORD`
- `CF_API_TOKEN`
- `CF_ZONE_ID`
- `CERTIFICATE_PEM`
- `PRIVATE_KEY_PEM`

### 2. Verify content pipeline

1. In `rizom-ai/brains`, generate docs from `docs/docs-manifest.yaml`.
2. Push generated `doc/*.md` files to `rizom-ai/doc-brain-content` using `DOCS_CONTENT_SYNC_TOKEN`.
3. Start this app with `GIT_SYNC_TOKEN`.
4. Confirm runtime directory sync pulls the content repo.

### 3. Verify app preview

1. Start with production-like env.
2. Trigger a preview rebuild.
3. Inspect `dist/site-preview`.
4. Verify:
   - `/`
   - `/docs`
   - `/docs/getting-started`
   - `/docs/content-management`
   - Discord connection
   - MCP auth

### 4. Deploy production

After preview verification:

1. confirm DNS target for `docs.rizom.ai`
2. confirm TLS cert/key secrets
3. run the generated deploy workflow
4. verify production routes and interfaces
